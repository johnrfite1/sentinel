# BATCH CARD A1 — repository identity and fail-closed enumeration

**Authority:** D-060(2), D-060(5). **Base SHA:** `f68d4d804de4d3b631e25fd539deecda5409f0d7`.
**This card is small on purpose. It claims completeness ONLY inside the boundary below.**

## THE INVARIANT — one

> **A project-owned entry point operates on the Sentinel repository that CONTAINS IT, and refuses
> rather than reporting a result it did not establish.**

Both halves are load-bearing. *Identity*: never the caller's current repository (D-060(2);
caller-relative behaviour is **not** a supported feature). *Fail-closed*: an unestablished fact
produces a refusal, never a clean-looking summary.

## BOUNDARY — explicit, and enumerated by file, shebang and ownership

**Entry points: 16.** Derived by listing `scripts/*` and `.githooks/*` and reading each file's
shebang, exec bit and tracked status — **not** by searching for a coding idiom, which is how the
abandoned contracts missed eight scripts and then a ninth.

All 16 are `#!/usr/bin/env bash`, executable, tracked:

`scripts/`: `check-class-coverage.sh`, `check-eval-codes.sh`, `check-findings-ledger.sh`,
`check-gate-immutability.sh`, `check-label-integrity.sh`, `check-label-prompt.sh`,
`check-rename-gate.sh`, `check-review-scope.sh`, `check-secrets.sh`, `check-suite-floors.sh`,
`check-type-strings.sh`, `check-vendor-honesty.sh`, `install-hooks.sh`, `mutate.sh`, `test.sh`
· plus `.githooks/pre-commit`

**Symbol boundary — the two paths under test:**
- **file enumeration:** `git ls-files` / `git diff --cached` uses in `check-review-scope.sh` and
  `check-secrets.sh`
- **blob reading:** `git show ":$f"` and working-tree reads in `check-secrets.sh`, **both default
  and `--staged` modes** — `test.sh:176` invokes the **default** mode

**Completeness is claimed inside this boundary only.** Not for the repository at large.

## TEST MATRIX — 13 cases, all required

| # | Case | Required |
|---|---|---|
| 1 | invoked from Sentinel's root | normal result |
| 2 | invoked from an unrelated directory | **still checks Sentinel** |
| 3 | invoked from inside a **foreign git repository** | **still checks Sentinel** |
| 4 | repository identity unresolved | **refuse** |
| 5 | a git command exits non-zero | **refuse** |
| 6 | a git command succeeds with **empty** output | **refuse** |
| 7 | a genuine **staged deletion** | **accept — protected control (D-059(3))** |
| 8 | ASCII filename carrying a planted credential | **blocked** |
| 9 | **non-ASCII** filename, byte-identical credential | **blocked** (fails today — `C4`) |
| 10 | secret guard **default** mode | fail-closed |
| 11 | secret guard **`--staged`** mode | fail-closed |
| 12 | `install-hooks.sh` against a **foreign** repository | **refuse; never write `core.hooksPath`** |
| 13 | pre-commit hook, repository-identity **mismatch** | **refuse** |

## CONTROLS — each must behave OPPOSITELY, or the matching test proves nothing

- Case 1 passes unchanged at base SHA for all 16 entry points.
- Case 7 (staged deletion) **must not** refuse — the false-failure D-059(3) forecloses.
- Case 8's ASCII twin **is** blocked today; case 9's accented twin is **not**. **That asymmetry is
  the discriminator** — a guard that blocked both would prove nothing.
- Cases 5/6: an unmutated run still assigns every tracked file and exits 0.
- Case 12: `install-hooks.sh` against **Sentinel** still succeeds.
- Case 13: a matching repository still commits.

## KNOWN FACTS THE AUTHOR SHOULD NOT RE-DERIVE

- `cd ""` returns 0 and does **not** abort, even under `set -euo pipefail`.
- `check-review-scope.sh:198`'s `git ls-files --error-unmatch … || continue` is `V3-N1`,
  **CONFIRMED**, and sits **upstream** of the UNASSIGNED check.
- `C4`'s root cause is `core.quotePath`. The staged-mode discriminator is `git diff --cached
  --raw -z` (status letter + blob OID; `-z` removes quoting). **It does NOT transfer to default
  mode, which uses `git ls-files` and has no status letters** — a default-mode discriminator must
  be established, and **if none exists that is a DECISION FORK for John, not an engineering
  choice.**
- `.githooks/pre-commit:4` uses an **unquoted** `repo_root=$(git rev-parse --show-toplevel)` and
  is outside any `scripts/*.sh` glob.
